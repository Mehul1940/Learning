🌳 Root Element

<html> - The Root Element

The <html> element represents the root of an HTML document.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Document</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>
💡 Note: Always include the lang attribute!

✅ HTML Best Practices

✅ DO:

  • ✅ Use semantic HTML tags
  • ✅ Always include DOCTYPE
  • ✅ Use lowercase for tags
  • ✅ Quote all attributes
  • ✅ Add alt text to images
  • ✅ Validate your HTML
  • ✅ Use proper indentation
  • ✅ Include meta viewport

❌ DON'T:

  • ❌ Use deprecated tags
  • ❌ Skip closing tags
  • ❌ Use inline styles everywhere
  • ❌ Forget alt text
  • ❌ Use multiple h1 tags
